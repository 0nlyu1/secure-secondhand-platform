# Tiny Second-hand Shopping Platform

Flask와 SQLite를 이용하여 구현한 소규모 중고거래 플랫폼입니다.

회원가입과 로그인, 상품 등록 및 검색, 사용자 간 메시지, 신고,
관리자 차단 기능과 가상 포인트 송금 기능을 제공합니다.

보안 코딩 관점에서 비밀번호 해시 저장, 서버 측 입력값 검증,
권한 검사, SQLAlchemy ORM, Jinja2 자동 이스케이프 등을 적용했습니다.

## 4. 설치 방법

### 4.1 저장소 복제

```bash
git clone <GitHub 저장소 주소>
cd <프로젝트 폴더명>
```

### 4.2 가상환경 생성

```bash
python3 -m venv .venv
```

### 4.3 가상환경 활성화

Linux 또는 WSL:

```bash
source .venv/bin/activate
```

Windows PowerShell:

```powershell
.venv\Scripts\Activate.ps1
```

### 4.4 패키지 설치

```bash
pip install -r requirements.txt
```

본 프로젝트는 SQLite 데이터베이스를 사용합니다.

애플리케이션 최초 실행 시 필요한 테이블이 생성되며,

데이터베이스 파일은 GitHub에 업로드하지 않습니다.

### 비밀번호 보호

- 비밀번호 평문 저장 금지
- Werkzeug를 이용한 비밀번호 해시 저장

### 입력값 검증

- 회원 아이디와 비밀번호 길이 검사
- 상품명, 설명, 가격 검사

### 인증 및 권한 검사

- 비로그인 사용자의 제한 기능 접근 차단
- 상품 등록자와 관리자만 상품 수정 및 삭제 가능
- 일반 사용자의 관리자 페이지 접근 차단

- Flask-SQLAlchemy ORM 사용
- 사용자 입력을 SQL문에 직접 연결하지 않음
- 포인트 송금 시 하나의 commit으로 데이터 변경
- 오류 발생 시 rollback 수행

### 출력값 처리

- Jinja2 자동 이스케이프 사용
- 사용자 입력에 `safe` 필터를 사용하지 않음
- 저장형 XSS 테스트를 통해 스크립트 미실행 확인

## 8. 보안 테스트

다음 공격 문자열을 직접 입력하여 테스트했습니다.

### SQL Injection 로그인 테스트

```text
' OR 1=1 --
```

테스트 결과 인증 우회에 실패했으며,
일반적인 로그인 실패 메시지가 출력되었습니다.

### SQL Injection 검색 테스트

상품 검색창에 동일한 문자열을 입력한 결과,
서버 오류나 전체 상품 노출 없이 일반 검색어로 처리되었습니다.

### 저장형 XSS 테스트

마이페이지 소개글에 다음 문자열을 저장했습니다.

```html
<script>alert(1)</script>
```

브라우저 경고창은 실행되지 않았으며,
입력 문자열이 텍스트로 표시되었습니다.

세부 테스트 결과는 `test.md`와 `evidence/` 폴더에서 확인할 수 있습니다.
